One word to erase from the dictionary forever: **irregardless** — the word everyone insists is not a word. Deleting it is the dictionary correcting itself.

## Run it

```sh
node main.ts
```

It writes the single word to `/output/entry.txt` (no trailing newline) and prints it to stdout. Deterministic, standard library only, no network.
